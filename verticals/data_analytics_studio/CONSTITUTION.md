# Конституция Data Analytics Studio (К-01 … К-07)

## К-01. Синтаксис Python/SQL
Артефакт компилируется (schema.py) и исполняется в песочнице.

## К-02. Решает задачу брифа
В коде используются поля/сущности из goal.

## К-03. Детерминированность
Нет сетевых вызовов и random без seed.
check_regex: requests\.(get|post)\(|random\.(random|randint)\((?![^)]*seed), message: Недетерминированный/сетевой код, severity: major

## К-04. Комментарии к метрикам
Каждая ключевая метрика пояснена комментарием.

## К-05. Эффективность запроса
SELECT без SELECT * по возможности.
check_regex: SELECT\s+\*, message: SELECT * — перечислите колонки, severity: minor

## К-06. Обработка ошибок
Читаемый код не падает: есть try/except или проверки пустых данных.

## К-07. Визуализация
Если запрошен дашборд — используется matplotlib/plotly с подписями осей.
