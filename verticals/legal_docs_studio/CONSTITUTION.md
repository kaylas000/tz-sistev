# Конституция Legal Docs Studio (К-01 … К-10)

Нарушение правила К-xx порождает код V-xx. Правила с `check_regex:` проверяются автоматически.

## К-01. Структура документа
Договор содержит заголовок, преамбулу, предмет, реквизиты сторон.

## К-02. Существенные условия
Присутствует раздел «Предмет» с конкретными обязательствами.

## К-03. Реквизиты сторон
Есть блок «Реквизиты сторон».
check_regex: (?s)^(?!.*Реквизиты).*$, message: Отсутствуют Реквизиты сторон, severity: critical

## К-04. Нумерация пунктов
Пункты пронумерованы (1.1, 1.2 ...).
check_regex: (?s)^(?!.*\n\d+\.\d+).*$, message: Нет нумерованных подпунктов, severity: major

## К-05. Срок и порядок расторжения
Указаны сроки действия и расторжения.

## К-06. Отсутствие противоречий
Не допускается «документ бессрочен» вместе с конкретным сроком действия.

## К-07. Юридические штампы без воды
Запрещена канцелярит-вода сверх квоты.

## К-08. Персональные данные
В согласиях на ПДн упомянут 152-ФЗ.

## К-09. Подписи
Есть место для подписей сторон.
check_regex: (?s)^(?!.*(Подпись|\(подпись\)|М\.П\.)).*$, message: Нет блока подписей, severity: major

## К-10. Язык документа
Документ на русском языке.
